# UI preview

Screenshots of the housing menu. The window follows the VMS Housing management layout: a grouped sidebar and one section at a time (My House, marketplace, bills, keys, upgrades, furniture). The accent is this resource's orange, `#ff7a18`, on a near-black panel.

Open `index.html` in a browser to scroll the shots, or run the live menu:

```
cd web
npm run dev
```

These images are for review. The menu players see is `web/dist`.
